# Day 15-2 — 샤프트 하단 Edge 오검출 개선

## 목표
Day015에서 발생한 샤프트 하단 Edge 오검출을 개선한다.

## 개선 방법
기존에는 중심 아래 영역에서 가장 강한 Edge를 선택했기 때문에
금속 표면 내부의 반사 Edge가 하단 Edge로 검출되었다.

Day015-2에서는 중심에서 아래 방향으로 Edge를 탐색하여
실제 샤프트 하단 외곽 Edge를 검출하도록 수정하였다.

## 결과

측정값:
[459, 459, 459, 459, 459, 459, 462]

평균 외경(pixel):
459.43

중앙값 외경(pixel):
459.0

## 결과 분석
Day015에서는 하단 Edge가 샤프트 내부에 검출되었으나,
Day015-2에서는 하단 Edge가 실제 샤프트 외곽까지 내려왔다.

7개 위치 중 6개 위치에서 459 pixel이 측정되어
측정값의 일관성도 향상되었다.
