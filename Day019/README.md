## 결론

Sub-pixel Edge 검출을 적용하여 정수 Pixel 기반 측정보다
측정 오차가 크게 감소하였다.

그러나 목표인 ±10 μm에는 아직 도달하지 못했으므로,
다음 단계에서는 Calibration 정밀화를 진행한다.
