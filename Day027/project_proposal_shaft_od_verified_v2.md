## 1. 프로젝트 개요

### 1.1 프로젝트명
[제안] **YOLO + OpenCV 기반 자동차 조향장치 샤프트 외경 자동측정 시스템 개발**

### 1.2 프로젝트 목적
[제안] 본 프로젝트는 자동차 조향장치에 사용되는 샤프트를 대상으로, 가공 후 외경을 카메라 영상으로 자동 측정하고 제품 규격과 비교하여 OK/NG를 자동 판정하는 AI 비전 측정시스템의 개발 가능성을 검토하는 것을 목적으로 한다.

[추론/검증필요] 본 프로젝트에서는 대상 샤프트를 **중요 특별특성 관리 대상으로 전제**하여 자동측정 시스템 개발 가능성을 검토한다. 단, 중요 특별특성의 공식 지정 여부는 고객도면, 관리계획서, 검사기준서 또는 사내 품질문서를 통해 최종 확인한다.

[사실] 대상 공정은 샤프트가 가공 전에 척 죠(Chuck Jaw)에 체결되고, 가공 완료 후에도 체결된 상태에서 촬영·측정하는 방식이다.

[제안] 개발 목표 흐름은 다음과 같다.

`이미지 입력 → 측정영역 설정 → 외곽 Edge 검출 → 정밀 외경 측정 → Pixel-mm 변환 → 규격 비교 → OK/NG`

## 2. 측정 대상 제품 소개

### 2.1 자동차 조향장치 샤프트
[사실] 측정 대상은 자동차 조향장치에 사용되는 샤프트이다.

[추론/검증필요] 조향장치는 운전자의 조향 입력을 바퀴 방향 변화로 전달하는 계통이며, 본 프로젝트에서는 이 계통에 사용되는 샤프트의 가공 외경을 자동 측정 대상으로 한다. 대상 샤프트의 정확한 장착 위치와 기능은 제품 도면 및 공식 제품자료를 기준으로 확인한다.

개념적인 조향 전달 구조는 다음과 같다.

`Steering Wheel → Steering Shaft/Column 계통 → Steering Gear → 조향 링크 → Wheel`

### 2.2 도면 요구사항과 외경 관리 필요성
[사실-도면] 대상 샤프트의 도면 외경 요구사항은 **Ø20.020 ±0.010 mm**이다.

[계산] 도면 기준치와 공차에 따른 허용범위는 다음과 같다.

- 하한: `20.020 - 0.010 = 20.010 mm`
- 상한: `20.020 + 0.010 = 20.030 mm`
- 전체 공차폭: `20.030 - 20.010 = 0.020 mm`

[추론/해석] 이와 같이 관리범위가 제한된 중요 가공치수는 가공 후 측정값이 도면 허용범위 안에 있는지를 일관되게 확인할 수 있는 검사체계가 필요하다.

[추론/검증필요] 외경 품질이 상대부품의 조립 및 기능에 미치는 구체적인 영향과 중요 특별특성의 공식 지정 근거는 제품 도면, 관리계획서, 검사기준서 및 품질문서를 통해 추가 확인한다.

## 3. 대상 공정

[사실] 대상 공정의 기본 흐름은 다음과 같다.

`샤프트 준비 → 가공 전 척 죠 체결 → 가공 → 가공 완료 → 척 죠 체결 상태에서 촬영 → 외경 측정 → 규격 비교 → OK/NG`

### 확인된 공정 조건
[사실]
- 샤프트는 가공 전에 척 죠에 체결한다.
- 외경 측정은 가공 완료 후 수행한다.
- 측정 시 샤프트는 척 죠에 체결된 상태이다.
- 외경 측정부위는 사전에 정해져 있다.

### 사전 검증이 필요한 조건
[추론/검증필요]
- 제품별 체결 상태 등에 따라 영상 내 샤프트 또는 측정부의 위치 변화가 발생할 가능성이 있다.
- 실제 위치 변화 여부와 변화량은 현재 확인되지 않았다.
- 위치 변화가 고정 ROI 방식에 영향을 주는지는 개발 과정에서 검증한다.

## 4. 문제 정의

본 프로젝트의 문제는 단순한 ROI 또는 Edge 검출의 기술 문제가 아니라, **제품 요구사항 → 품질관리 필요성 → 생산·경제적 부담 → 자동측정 기술 과제**의 흐름으로 정의한다.

### 4.1 문제의 출발점 — 제품과 고객 도면 요구
[사실] 측정 대상은 자동차 조향장치에 사용되는 샤프트이며, 가공 후 외경을 검사한다.

[사실-도면] 고객 도면에서 요구하는 외경은 **Ø20.020 ±0.010 mm**이다.

[계산] 따라서 허용범위는 **20.010~20.030 mm**, 전체 공차폭은 **0.020 mm**이다.

[추론/해석] 가공 후 샤프트가 이 허용범위를 만족하는지를 안정적으로 확인하는 것이 본 프로젝트의 품질 문제의 출발점이다.

### 4.2 중요 가공부위의 품질관리 문제
[추론/검증필요] 대상 샤프트는 중요 특별특성 관리 대상으로 전제하여 프로젝트를 기획한다. 다만 공식 지정 여부와 구체적인 기능 영향은 고객도면, 관리계획서, 검사기준서 등으로 최종 확인한다.

[추론/해석] 제한된 공차범위를 안정적으로 관리하려면 단순히 한 번 측정값이 규격 안에 들어오는 것뿐 아니라 측정시스템의 정확성, 반복성 및 재현성을 함께 확인할 필요가 있다.

### 4.3 생산·경제적 문제
[추론/해석] 외경의 측정·판정·기록을 반복적으로 수행하는 공정은 작업시간과 인력 투입을 필요로 하며, 생산량이 증가할수록 검사 운영 부담이 커질 가능성이 있다.

[기대효과] 자동측정 시스템이 요구 성능을 확보하고 현장에 적용될 경우 검사시간 단축, 반복 측정·판정 업무 감소, 검사인력 운영 효율화, 측정결과 자동기록 및 품질이력 관리 등의 경제적 가치를 기대할 수 있다.

[주의] 현재는 생산량, 검사 Cycle Time, 실제 투입인원, 인건비, 설비투자비, 유지관리비, 품질비용 등의 경제성 원자료가 충분하지 않으므로 **검사자 감축 인원, 연간 비용절감액, ROI를 확정 수치로 제시하지 않는다.**

[제안] 기술 검증 이후 실제 생산 데이터를 이용하여 경제성을 별도로 산출하고, **기술성 + 경제성**을 함께 평가하여 현업 도입 여부를 판단한다.

### 4.4 자동측정을 위한 기술 문제
[사실] 외경 측정부위는 사전에 정해져 있다.

[추론/검증필요] 척 체결 상태 등에 따라 영상 내 측정부의 좌표가 실제로 얼마나 변화하는지는 확인되지 않았다.

[제안] 우선 고정 ROI를 검토하고, 위치 변화가 측정 안정성에 영향을 주는 것이 확인될 경우 YOLO 기반 ROI 자동탐지를 적용한다.

[추론/검증필요] 금속 표면의 반사광, 가공무늬, 조명 및 배경조건은 실제 외곽선과 다른 밝기 변화를 만들 가능성이 있다.

[제안] OpenCV 기반 Gradient/Edge 분석, Multi-point, Line Fitting, Median/Outlier, Sub-pixel 등의 방법을 검토하여 실제 상단·하단 외곽 Edge를 안정적으로 측정한다.

### 4.5 최종 문제 정의
> **자동차 조향장치 샤프트의 도면 요구사항 Ø20.020 ±0.010 mm를 안정적으로 관리하기 위해, 가공 후 외경을 자동 측정·판정할 수 있는 비전 측정시스템을 개발하고, 측정성능과 경제성을 검증하여 현업 적용 가능성을 판단할 수 있는가?**

## 6. 데이터 확보 및 구조 계획

[제안] 데이터는 목적별로 분리하여 관리한다.

`실촬영 원본 데이터 → ROI/YOLO 개발용 데이터 → 정밀측정 개발용 데이터 → Calibration 데이터 → 독립 Validation 데이터 → 반복성/재현성 평가 데이터`

### 6.1 원본 이미지 데이터
[제안] 실제 공정조건을 반영한 샤프트 이미지를 확보한다.

[제안] 가능한 경우 다음 변동요인을 포함한다.
- 제품 개체 차이
- 촬영 시점 차이
- 조명 변화
- 제품 위치 변화
- 금속 표면 상태
- 정상/비정상 조건

[주의] 제안 단계에서 실제 필요한 데이터 수량을 임의로 확정하지 않는다.

### 6.2 YOLO 학습/검증 데이터
[제안] ROI 자동탐지가 필요하다고 판단될 경우 원본 데이터를 Training과 Validation으로 분리하고 측정 대상 또는 측정영역을 Labeling한다.

### 6.3 Data Augmentation
[제안] 학습 데이터가 부족한 경우 밝기, Contrast, 위치, Scale 등 실제 공정에서 발생 가능한 변화를 반영한 데이터 증강을 검토한다.

[주의] 증강 데이터는 학습 보조 데이터이며 새로운 실제 제품에서 얻은 독립 검증 데이터와 동일하게 취급하지 않는다.

### 6.4 Calibration 데이터
[제안] 실제 기준치가 확인된 복수의 샘플 또는 기준물을 이용하여 Pixel-mm 변환관계를 설정한다.

### 6.5 독립 Validation 데이터
[제안] Calibration과 알고리즘 개발에 사용하지 않은 별도 데이터를 확보하여 최종 측정성능을 평가한다.

### 6.6 반복성·재현성 데이터
[제안] 동일 제품의 반복 측정과 실제 공정에서 의미 있는 조건 변화를 포함한 시험 데이터를 별도로 확보한다.

## 7. 기술 구성 계획

[제안] 시스템은 다음 구조로 설계한다.

`Camera/Image → ROI 설정 → 필요 시 YOLO 위치 탐지 → OpenCV 전처리 → Gradient → Upper/Lower Edge → Multi-point → Line Fitting/Median/Outlier → Sub-pixel → Pixel 외경 → Calibration → mm 외경 → 규격 비교 → OK/NG`

### 7.1 YOLO
[제안] YOLO는 외경 치수를 직접 측정하는 기술이 아니라 영상 내 제품 또는 측정영역의 위치를 자동으로 찾기 위한 후보 기술로 검토한다.

### 7.2 OpenCV
[제안] OpenCV는 ROI 내부에서 실제 외곽 Edge를 검출하고 상단 Edge와 하단 Edge 사이의 거리를 계산하는 정밀측정 엔진으로 활용한다.

### 7.3 Gradient / Edge
[제안] 영상의 밝기 변화와 방향을 분석하여 샤프트와 배경의 경계 후보를 탐색한다.

### 7.4 Multi-point / Line Fitting / Median / Outlier / Sub-pixel
[제안] 단일 지점 측정의 위험을 줄이고, Edge 위치를 안정적으로 추정하며, Pixel 이하 위치 추정을 검토하기 위한 정밀측정 방법으로 적용 가능성을 검토한다.

## 8. 검증 계획

### 8.1 ROI 검증
[제안]
- 실제 영상 내 위치 변화량 측정
- 고정 ROI와 자동 ROI 방식 비교
- ROI 방식에 따른 최종 측정값 변화 평가

### 8.2 Calibration 검증
[제안] 한 개의 기준값에만 의존하지 않고 가능한 경우 복수 기준값을 이용하여 Pixel-mm 관계를 확인한다.

### 8.3 정확성 검증
[제안] 독립 Validation 데이터를 이용하여 측정오차, 절대오차, MAE, 최대 절대오차, 허용오차 초과 여부를 평가한다.

### 8.4 Repeatability / Reproducibility / Gage R&R
[제안] 동일 조건 반복 측정, 실제 공정조건 변화, 필요 시 Gage R&R을 통해 측정시스템 변동을 정량적으로 평가한다.

- Pixel-mm 자동 변환 기술 확보 가능
- 외경 자동측정 및 규격 자동판정 가능성
- 측정 데이터 디지털화 기반 마련
- 생산라인 자동검사 시스템으로 확장 가능한 기술구조 확보

### 10.2 예상 품질성과
[기대효과]
- 검사기준 일관성 향상 가능성
- 수작업 측정 및 판정 편차 감소 가능성

- 측정이력 추적관리 강화 가능성

### 10.3 예상 생산성 성과
[기대효과]
- 반복 검사작업 자동화 가능성
- 검사시간 단축 가능성
- 작업자의 반복 측정·기록 업무 감소 가능성
- 검사인력 감축 또는 재배치 가능성

### 10.4 예상 경제적 성과
[기대효과] 검사 자동화가 현장에 적용될 경우 검사시간 단축, 반복 검사작업 감소, 검사인력 운영 효율화, 수기 기록 감소 및 품질이력 관리 효율화 등의 경제적 가치가 발생할 가능성이 있다.

[주의] 현재 경제성 원자료가 충분하지 않으므로 **검사자 2명 감축, 연간 1억 원 절감 등 구체적인 수치를 제안서의 확정 성과로 사용하지 않는다.**

[제안] 기술 검증 이후 다음 자료를 확보하여 경제성을 산출한다.
- 연간 생산량 및 검사 수량
- 제품당 검사 Cycle Time
- 검사 투입인원 및 실제 투입시간
- 인건비
- 비전설비 투자비
- 유지관리비
- 재검사·불량유출·품질비용 자료

[제안] 위 자료를 이용하여 `연간 검사시간 절감`, `인력 운영효과`, `연간 절감가능액`, `투자회수기간(ROI)`을 산출하고 기술성 검증결과와 함께 최종 도입 여부를 판단한다.
