# Day 15 — ROI 중앙부에서 여러 위치의 외경을 측정하고 평균값을 구하기

## 목표
샤프트 ROI의 중앙 영역에서 여러 x 위치의 위/아래 Edge를 검출하고
각 위치의 외경(pixel)을 계산한 뒤 평균값과 중앙값을 구한다.

## 결과
측정값:
[261, 243, 253, 250, 242, 243, 245]

평균 외경(pixel):
248.14

중앙값 외경(pixel):
245.0

## 확인된 문제
상단 Edge는 비교적 안정적으로 검출되었으나,
하단 Edge가 실제 샤프트 외곽이 아닌 금속 표면 내부의 강한 Edge를
선택하는 오검출이 발생하였다.
